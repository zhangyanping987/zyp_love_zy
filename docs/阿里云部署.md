# 阿里云 OSS：媒体加速（推荐）

阿里云 **Bucket 外网域名**可以正常访问图片、视频、JSON，但打开 `index.html` 会触发下载（响应头带 `Content-Disposition: attachment`）。  
香港等地域的 `oss-website-*` 静态网站域名往往不可直接用；要「整站都在 OSS」必须绑定**自有域名**（或 CDN 加速域名）。

因此推荐混合方案：

| 内容 | 放哪里 | 原因 |
|------|--------|------|
| 网页 HTML / JS / CSS / photos.json | GitHub Pages | 可当网站打开 |
| 图片、视频、BGM | 阿里云 OSS | 国内加载更快 |

当前线上：

- 网站：`https://zhangyanping987.github.io/zyp_love_zy/`
- 媒体：`https://zyp-love-zy.oss-cn-hongkong.aliyuncs.com/media/...`

## 一、控制台（已完成可跳过）

1. Bucket `zyp-love-zy`，地域香港，**公共读**
2. 可选：数据管理 → 静态页面（对桶域名无效，绑自定义域名时才有用）
3. RAM AccessKey（仅 OSS 权限）

## 二、上传媒体到 OSS

```bash
cd ~/Projects/zy-album
export OSS_BUCKET=zyp-love-zy
export OSS_ENDPOINT=oss-cn-hongkong.aliyuncs.com
export OSS_AK=你的AccessKeyId
export OSS_SK=你的AccessKeySecret

./scripts/deploy-aliyun.sh
```

脚本会构建并把 `dist/`（含 `media/`）同步到桶根。  
不必用桶域名打开网站；GitHub Actions 构建时已设置：

`VITE_ASSET_BASE=https://zyp-love-zy.oss-cn-hongkong.aliyuncs.com/`

本地验证媒体：

```bash
curl -sI "https://zyp-love-zy.oss-cn-hongkong.aliyuncs.com/media/images/01_maozi_01.webp"
# 应看到 Content-Type: image/webp，且能正常显示
```

## 四、若要坚持「整站都在阿里云」

1. 买一个域名（香港桶一般无需国内备案）
2. 控制台：Bucket → 传输管理 / CDN → 绑定自定义域名，开启静态网站
3. 把 `vite.config` 的 `base` 改成 `/`，构建时不要设 GitHub 的 `VITE_BASE`
4. 用自定义域名访问（不要用 `*.oss-cn-hongkong.aliyuncs.com`）
