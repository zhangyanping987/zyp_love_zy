# 阿里云 OSS 媒体加速（华东）

香港桶对大陆是跨境链路，容易慢。推荐 **华东（杭州）** 公共读桶只放媒体；网页继续用 GitHub Pages。

| 内容 | 地址 |
|------|------|
| 网站 | https://zhangyanping987.github.io/zyp_love_zy/ |
| 媒体桶（示例） | `zyp-love-zy-hz` @ `oss-cn-hangzhou` |
| 媒体 URL | `https://zyp-love-zy-hz.oss-cn-hangzhou.aliyuncs.com/media/...` |

混合方案下用桶外网域名拉图/视频即可，**不必备案、不必绑自定义域名**。

## 一、新建华东 Bucket

1. 打开 [创建 Bucket](https://oss.console.aliyun.com/bucket)
2. 名称：`zyp-love-zy-hz`（被占用就换名，并改仓库里 `VITE_ASSET_BASE`）
3. 地域：**华东1（杭州）**
4. 冗余：本地冗余即可
5. 建好后：
   - **阻止公共访问** → 关闭
   - **读写权限** → **公共读**

旧香港桶 `zyp-love-zy` 可之后在控制台清空删除，避免双份费用。

## 二、本机上传

```bash
cd ~/Projects/zy-album
export OSS_BUCKET=zyp-love-zy-hz
export OSS_ENDPOINT=oss-cn-hangzhou.aliyuncs.com
export OSS_AK=你的AccessKeyId
export OSS_SK=你的AccessKeySecret
./scripts/deploy-aliyun.sh
```

验证：

```bash
curl -sI "https://zyp-love-zy-hz.oss-cn-hangzhou.aliyuncs.com/media/thumbs/01_maozi_01.webp"
# 200 + image/webp
```

## 三、网站

密码仍是 `zypzy`。
